Two real, concrete gaps were found and fixed:
  - **Timeouts too aggressive for a real device.** `AppSettings.allowBackgroundDownloads` defaults to `false` (no Android foreground service keeps the connection alive while the app is backgrounded), so a normal "lock the phone for a bit" reliably tripped this app's own stall-timeout wrapper (45s for Whisper, 90s for LLM/embedding) well before the user meant to interrupt anything - raised to 3 minutes (`HttpModelDownloadService`'s default `stallTimeout`, `LlamaDartLlmEngine`/`LlamaDartEmbeddingEngine`'s `_downloadStallTimeout`) and the overall cap from 15 to 30 minutes.

### Phase 6B (Hybrid Retrieval Engine) completion detail
- **Completed:** Full detail in ADR-037 (docs/v2/implementation/03-decisions.md). `HybridRetrievalPipeline` fuses chunk-level BM25 keyword search (new `knowledge_chunks_fts` FTS5 external-content table, migration v14) with the existing vector search via Reciprocal Rank Fusion (`rrfK=60`), a small capped recency boost (bounded so it can never override a genuine relevance-rank difference — a real bug in the first implementation, caught by this phase's own invariant test before it shipped), evidence-based confidence scoring (`RetrievalConfidence`, a real recomputed cosine similarity, not a guess), 6-way pre-retrieval query classification, and token-budget-aware context assembly that never truncates a chunk mid-sentence. When confidence is `low`/`none`, the app answers from the local LLM's own general knowledge (`answerGeneralKnowledgeStream`, a distinct prompt/temperature) instead of a fixed refusal string, with a persisted `AnswerProvenance` shown distinctly in the UI and `sources` always empty for that path (no fabricated citations, ever). `WorkspaceChatUseCase` rewired onto the new pipeline; `RetrievalEngine`/`DefaultRetrievalEngine`/`BruteForceVectorStore`/`content_fts`/`AskAboutMeetingsUseCase` are all untouched and still exported.
- **Not started this pass:** The Productivity Toolkit rename and licensing/premium architecture — the other two of ADR-035's five approved-but-unbuilt directions, still unbuilt.
- **Tests:** `flutter analyze` — clean. `flutter test` — passing.
- **Known limitations:** RRF/recency/confidence-threshold constants (`rrfK=60`, `recencyHalfLifeDays=30`, thresholds 0.55/0.35/0.20) are disclosed, unvalidated starting points — no real device or real embedding model is available in this environment to tune them against (same standing limitation as ADR-011, R-04/R-18/R-19).

### `AppDatabase` FTS5 real-device crash fix (`database-fts5-fix`) completion detail
- **Completed:** Full detail in ADR-038 (docs/v2/implementation/03-decisions.md). The first real-device install of the release APK crashed on first launch (`DatabaseException(no such module: fts5)`) because plain `sqflite`'s Android platform-channel backend talks to the OS's own bundled SQLite, whose FTS5 support is not guaranteed — a gap `flutter test` never exercised because the test suite already forced `sqflite_common_ffi`'s FTS5-capable engine via `databaseFactory = databaseFactoryFfi`, but production (`main.dart`) never did the same. Fixed by making `AppDatabase.open()` do the identical override in production: `sqfliteFfiInit()` + `databaseFactory = databaseFactoryFfi`, backed by the new `sqlite3_flutter_libs` dependency (bundled, FTS5-compiled native SQLite per Android ABI). Zero changes to any of the 13 existing migration files or any repository — this is an implementation swap behind an already-abstracted interface, not an architecture change. A defensive `migrateLegacyDatabaseFileIfNeeded` copies forward any database that had already been created under the old platform-channel path (none was found on the device that surfaced this bug — every prior attempt crashed during `onCreate` before a database existed — but the copy-forward exists for correctness regardless).
- **Tests:** New `migrateLegacyDatabaseFileIfNeeded` unit tests; full suite otherwise unaffected.
- **Known limitations:** Release APK size grows further (a native SQLite library now bundled per ABI, on top of llamadart/whisper.cpp/ffmpeg's own) — not separately measured, disclosed as a known cost.
